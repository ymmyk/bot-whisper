# Push benchmark 2026-10-23

Reduced run (time-capped): subscriber steps `1000 4000` (cumulative), steady rates `10 100` msg/s for 30s each, heartbeat 30s, one client-side blip and one server restart per target.

- Host: Mac16,10, 10 cores, 24 GiB, macOS 26.6.2
- kern.maxfiles=184320 kern.maxfilesperproc=92160 somaxconn=128 ephemeral ports 49152-65535 tcp msl=15000ms; ulimit -n 65536 (this shell only)
- Single loopback source address (127.0.0.1; aliases need sudo), so total concurrent client connections stay under the ~16k ephemeral-port budget.
- ntfy 2.32.0 built from source with the server (brew bottle is client-only on macOS), config `ntfy/server.yml`; ours: `push-server` (axum 0.8.9, tokio 1.54.1); rustc 1.99.1
- RSS from `ps -o rss`; CPU% = delta of `ps -o time` over the sample window (one core = 100%).
